# Tier 2 rewrite list

Every use, in a migrated model under `src/Sts2Emulator/Core2/Models/`, of a Tier 1 member of the handler
context (`K`, `World`, `OldBuffs`, `OldCombat`, `Enemy`: `Core2/HookCtx.cs`). A Tier 2 runtime has none of
them, so each line is rewritten when its model moves to the Tier 2 state. Generated by
`ModelSourceScanTests` (`SPIRELINE_WRITE_TIER2_LIST=1 dotnet test src/Sts2Emulator.Tests --filter
FullyQualifiedName~ModelSourceScanTests`); regenerate after a batch lands. The same test fails on `OldState.`,
`OldCreatures.` and static mutable state in a model, so those never appear here.

No migrated model uses a Tier 1 member yet.
